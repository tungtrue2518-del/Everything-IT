Find inactive AD users

Lists enabled accounts that have not signed in for 90 days and exports them to CSV for review.

# Lists enabled AD accounts with no sign-in for 90+ days
Import-Module ActiveDirectory
$cutoff = (Get-Date).AddDays(-90)

Get-ADUser -Filter {Enabled -eq $true -and LastLogonDate -lt $cutoff} -Properties LastLogonDate |
  Select-Object Name, SamAccountName, LastLogonDate |
  Sort-Object LastLogonDate |
  Export-Csv -Path .\inactive-users.csv -NoTypeInformation

Low disk space warning

Checks every fixed drive and warns when free space drops below a threshold.

# Warns when any fixed drive drops below 15% free space
$threshold = 15

Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" | ForEach-Object {
  $free = [math]::Round($_.FreeSpace / $_.Size * 100, 1)
  if ($free -lt $threshold) {
    Write-Warning "$($_.DeviceID) has only $free% free"
  }
}

TLS certificate expiry check

Connects to each host and prints how many days are left before its certificate expires.

# Prints days until each site's TLS certificate expires
import socket, ssl, time

HOSTS = ["example.com", "intranet.example.com"]

def days_left(host, port=443):
    ctx = ssl.create_default_context()
    with socket.create_connection((host, port), timeout=5) as sock:
        with ctx.wrap_socket(sock, server_hostname=host) as tls:
            expires = ssl.cert_time_to_seconds(tls.getpeercert()["notAfter"])
    return int((expires - time.time()) // 86400)

for host in HOSTS:
    print(f"{host:30} {days_left(host):>4} days")

Backup rotation

Keeps the newest 14 backup archives in a folder and deletes older ones.

#!/usr/bin/env bash
# Keeps the 14 newest backup archives and deletes the rest
set -euo pipefail
BACKUP_DIR="/srv/backups"
KEEP=14

find "$BACKUP_DIR" -maxdepth 1 -name '*.tar.gz' -printf '%T@ %p\n' |
  sort -rn | tail -n +$((KEEP + 1)) | cut -d' ' -f2- |
  xargs -r -d '\n' rm --
